# Overview

This project is a Pediatric BMI Analysis and Visualization System designed to demonstrate my ability to develop software using the Java programming language.

The software manages children and their health control records, calculates Body Mass Index (BMI) from weight and height, and provides classifications based on age-related growth information. The application uses a Java Spring Boot backend with a relational database to store and manage the information.

The purpose of writing this software is to strengthen my Java programming skills, especially object-oriented programming, classes, methods, collections, conditionals, loops, interfaces, and working with data stored in a relational database. It also provides an opportunity to practice building a complete backend application that can be tested through its API.

[Software Demo Video](https://drive.google.com/file/d/1DS8yj1jIPDf68vzDUREM8KZYF-cCJ8vQ/view?usp=sharing)

# Development Environment

I developed this software using IntelliJ IDEA and Visual Studio Code, Git and GitHub for version control, Maven for project management, and MySQL as the relational database.

The programming language used is Java. The application was developed with Spring Boot, Spring Data JPA, and Hibernate for the backend and database persistence. The project also uses the Java Collection Framework, including List collections, to manage groups of child records and control records.
